# Offline camera tools

SPDX-License-Identifier: CC-BY-4.0

See [camera integration](../README.md) for installation, platform limits and
[data provenance](../NOTICE.md). These tools are separate from real-time
libcamera and must not share its active camera graph.

`cam-snap [options] OUT.jpg` captures packed GRBG RAW10, subtracts black level
63.75, applies four-illuminant shading and optional per-unit residual,
Malvar demosaic, reference-based AWB, interpolated CCM and a 14-bit reference
gamma, optional guided-filter denoise, coring/sharpening and 180-degree
software rotation. Processing uses bands to limit memory.

| Option | Meaning |
| --- | --- |
| `--full` | Capture 2608x1960 and downsample 2x; may reload module |
| `--native` | Retain full dimensions with --full |
| `--no-ae` | Keep current sensor exposure/gain |
| `--denoise N` / `--sharp N` | Strength; zero disables respective stage |
| `--target N` | Central green AE target above black, default 86 DN |
| `--no-residual` / `--raw FILE` | Ignore local calibration / retain RAW10 |
| `--no-rotate` | Keep native upside-down mounting orientation |

`cam-flat --target 300` measures a uniformly illuminated diffuser; add
`--save` to create local residual.json. The tool's default target is 500;
300 is a conservative example that leaves headroom. Use `--frames N` to
change averaging and `--out FILE` for another output location. The residual
uses a 13x17 grid for each of R/Gr/Gb/B, normalized at the centre. Never
copy a different unit's residual or treat nonuniform illumination as shading.

`make_libcamera_tuning.py` reads the reference JSON and optional local
residual, then writes `libcamera-ccm-lsc-sections.yaml`. Default grid
orientation is 180 degrees; `--no-rot180` is for unflipped input, and
`--no-residual` selects generic vendor values. Merge the emitted sections
into the full tuning file. The committed sections/YAML contain no residual.

`otp/s5k_i2c.py` provides a limited I2C_RDWR register interface. Its whitelist
deliberately excludes the OTP-program command. `otp/sram_test.py` requires a
local `otp/otp_dump.json`, streams frames and writes only candidate volatile
SRAM/shading registers. This is a failed calibration experiment retained for
contributors, not a supported calibration procedure. It assumes CCI bus 3
and an exclusive, powered camera; inspect/adapt before use. It is never run
by the service. No OTP dump is included or generated by installation.
